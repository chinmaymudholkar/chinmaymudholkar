# Chinmay Mudholkar | Test Automation and much more...

Hello! I'm Chinmay. For over two decades, I've been working with software - automating tests and builds, and doing my best to make sure things actually work for the people who use them.

## The Journey (So Far)

My automation adventures began in the era of **QTP 8.5**, a time when VBScript was the language of choice and "The Cloud" was still just a meteorologist's concern. Since those early days of binary format object repositories and recording and playback, I've had the privilege of evolving alongside the industry, transitioning through various tools, frameworks, and design philosophies.

I've learned that while tools change, the core mission remains the same: ensuring that software doesn't just pass technical checks, but actually solves business challenges and serves the real-world needs of end users. I try not to focus only on edge cases or clever frameworks, but on building reliable, maintainable systems that help teams move quickly without worrying about unexpected surprises.

## The Digital Toolbox

I've had the chance to work with a wide mix of tools and technologies, and each has shaped how I work:

-   **Languages:** C#, Python, Java, JavaScript, and yes, VBScript will always have a nostalgic corner in my brain.
-   **Automation:** Playwright, Selenium WebDriver, TestNG, NUnit, JUnit.
-   **Infrastructure & Tools:** GitHub Actions, Jenkins, Allure, Maven, NuGet, Git.
-   **Focus Areas:** Framework Architecture (UI, API and data), CI/CD, Test Management, and ensuring "**__it works on my machine__**" is a phrase of the past.

## About This Repository

These repositories are basically my digital sandbox - a place where I stash patterns, experiments, and ideas I've picked up along the way. It's pretty simple on purpose - just a collection of artefacts that might be helpful to anyone browsing through.

Feel free to poke around, borrow anything, or tell me if you see a better way to do something. I'm still learning too.

*"Testing is an infinite act of humility."* (And if it's not, a failing CI/CD pipeline usually helps it get there.)
