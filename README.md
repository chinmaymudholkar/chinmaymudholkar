# Chinmay Mudholkar | Test Automation & Quality Engineering

Hey there! 👋 I'm Chinmay, and I've been breaking (and then automating the fixing of) software for over 20 years. 

My journey into the world of automation started back when **QTP 8.5** was the "cool kid" on the block and "The Cloud" was just something that brought rain. Since those days of VBScript and heavy IDEs, I’ve evolved alongside the industry—transitioning through a spectrum of languages, tools, and methodologies. 

I’ve spent the last two decades in a polite but persistent argument with software, trying to convince it to do what it’s told. Whether I'm building frameworks or supporting teams, my goal is to catch those "creative" edge cases before they reach production - because if there's one thing two decades has taught me, it's that "it shouldn't do that" is usually the start of a very long night.

### The Toolkit

Over the years, I've collected a fair share of tools and languages. Here’s a snapshot of my "digital belt":

- **Languages:** C#, Python, Java, JavaScript, VBScript (the OG).
- **Automation Frameworks:** Playwright, TestNG, Selenium WebDriver, NUnit, JUnit.
- **Reporting & Tools:** Allure, Maven, NuGet, Git, CI/CD (GitHub Actions, Jenkins).
- **Specialties:** Test Management, Framework Architecture with UI, API and ETL Automation.
